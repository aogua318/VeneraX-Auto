## What's Changed

### Added
- New "First Page / Previous Chapter" and "Last Page / Next Chapter" hardware key actions: jump to the current chapter's first/last page first, then switch chapter on the next press
- The bottom first/last page buttons now share the same two-step behavior

### Fixed
- Seamless continuous reading no longer snaps back to the old chapter after switching to a previous chapter
- A failed previous-chapter jump no longer switches to a neighbouring comic in the bookshelf
- Auto scroll at chapter end no longer falls back to the next comic while the next chapter is still loading
